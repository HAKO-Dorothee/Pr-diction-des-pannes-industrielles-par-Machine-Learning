# Prédiction-des-pannes-industrielles-par-Machine-Learning
Analyse des données, feature engineering et optimisation de modèles de Machine Learning pour prédire les pannes des équipements industriels.

Développement de modèles de classification pour prédire les défaillances de machines industrielles à partir de données de fonctionnement. Réalisation du nettoyage des données, de l’analyse exploratoire et du feature engineering (calcul de la puissance moteur). Entraînement et optimisation de modèles (Decision Tree, Logistic Regression, Random Forest) avec GridSearchCV, atteignant 99 % d'accuracy et 98 % de précision sur la classe des pannes.
